# 原版刷牙引导与音频迁移

来源：用户旧项目 https://github.com/caterpi11ar/dentic ，固定提交 `370f64990c0575b6080706eb7c5293cdab8e8144`。

- `ToothScene`：保留 28 颗牙齿的几何布局与原 15 步高亮映射；原舌面步骤沿用下排高亮提示。
- `BrushActiveState` / `BrushTimer` / `StepIndicator`：恢复米白背景、陶土色高亮、圆环、提示卡、分段进度与圆形暂停控制。样式限制在引导组件，尺寸适配当前 750 设计宽度，不改全局 Tailwind tokens。
- `BrushCountdownOverlay`：恢复整屏 3/2/1，保留当前项目的暂停与退出入口。
- `BrushCompletedState`：恢复勾选图案、用时/步骤/连续天数三栏与晨晚完成提示；返回现有按天旅程。没有恢复旧首页/底栏或新增分享功能。
- `src/assets/audio`：18 个 MP3 原样复制，合计 592135 字节；开始、15 步、完成语音和 step-ding。逐文件 SHA-256 见 `original-guide-audio.json`。
- 音频位于 `src/static/assets/brush-audio`，打包为实体文件，微信输出 `dist/assets/brush-audio`，H5 输出 `dist/h5/assets/brush-audio`；运行中不访问远程资源，不使用内联 data URI 音频。
- 保留原独立语音/提示音开关和双音轨；暂停/切后台停音，继续时重播当前步骤，卸载销毁播放器。浏览器或系统拒绝播放时安静降级。
- 当前 150 秒流程、晨晚记录、累计天数和未完成不保存规则保留；语音未结束时下一步骤会替换它，与旧项目一致。

测试：类型检查、原有 7 项刷牙领域用例、音频调用顺序/独立开关/释放/18 文件哈希，以及微信与 H5 构建。浏览器检查仅证明 H5 布局与音频文件可访问；微信开发者工具和真机音频、亮屏、后台行为仍须单独验证。

迁移前备份：`.local/backups/original-guide-20261031/before.zip`。现有 skills、来源清单与依赖锁文件保持原样。

## 复刻范围修正

按用户最新要求，旧版仅用于刷牙中的牙齿引导及原音频。准备页和完成页恢复当前项目的绿色按钮、角色与完成卡片；首页、任务、成就及我的保留现有设计。上文三栏完成页迁移描述已被本次修正取代。

## 最终范围：仅牙齿模块和音频

旧版仅保留 ToothScene 的几何布局、区域映射和牙齿高亮，以及原音频。已移除旧页面框架、圆环、提示卡、旧暂停按钮、整屏倒计时及分段组件；其余全部使用当前多邻国系的白底、绿色进度/厚底按钮、蓝色计时徽章与提示卡。此前关于旧页面风格的描述均为迁移历史，当前不再使用。
