## 刷牙会话

- 状态流转：idle → countdown → brushing ⇄ paused → completed；完成后可返回 idle。
- 每次开始重置会话，先 3 秒倒计时，再开始刷牙。
- 固定 15 步，每步 10 秒，刷牙用时共 150 秒；倒计时和暂停时间不计入 elapsedTime。
- 只有 countdown / brushing 时每秒推进；paused 不减少剩余时间，不增加用时。
- 当前步骤结束自动进入下一步；第 15 步结束才进入 completed。
- 仅完成时保存记录，同一次完成副作用只处理一次。未完成的会话不记作完成，不生成开始/放弃事件。
- 进行中的会话仅在内存中，旧实现未持久化断点。不要把页面卸载后的自动续刷或后台计时精度当作已有能力。
- 反馈：步骤提示、当前区域、剩余秒数、N/15、下一步提示；开始/步骤/完成语音、步骤提示音、震动、刷牙与倒计时期间亮屏，卸载清理音频和亮屏。设置影响声音，平台能力失败不应阻断流程。
- 首次引导由本机 onboarding_seen 标识控制。旧实现在展示引导时即标记已见。

顺序必须保留（第 15 步为舌面）：

| --- | --- |
| 1 | 上牙外侧左 |
| 2 | 上牙外侧前 |
| 3 | 上牙外侧右 |
| 4 | 上牙内侧左 |
| 5 | 上牙内侧前 |
| 6 | 上牙内侧右 |
| 7 | 上牙咬合面 |
| 8 | 下牙外侧右 |
| 9 | 下牙外侧前 |
| 10 | 下牙外侧左 |
| 11 | 下牙内侧右 |
| 12 | 下牙内侧前 |
| 13 | 下牙内侧左 |
| 14 | 下牙咬合面 |

沿用旧步骤提示：牙刷倾斜 45° 对准牙龈线、小幅水平震颤；前牙内侧竖刷，咬合面来回刷，最后轻刷舌面。具体文案以旧 src/constants/brushing-steps.ts 为依据，不将实现说明扩展为疗效承诺。

## 日期、记录与存储

按设备本地时间，以**完成时刻**确定业务日期和晨晚时段：
- 业务日从 04:00 起，04:00 前归前一天。
- morning 为 04:00–11:59，其他时刻为 evening。
- 例如 10 月 28 日 03:59 完成为 10 月 27 日 evening；04:00 为 10 月 28 日 morning；12:00 为当天 evening。

完成记录结构：

```ts
interface BrushingRecord {
  date: string // 业务日 YYYY-MM-DD
  session: 'morning' | 'evening'
  completed: boolean
  duration: number // 秒；完整流程为 150
  completedSteps: number // 完整流程为 15
  timestamp: number // 完成时刻，毫秒
}
```

- Taro 本地存储 key：brushing_records。按 date + session 去重，同业务日同时间段再次完成覆盖原记录，保留最新完成时间。
- 只统计 completed=true 的记录。同一天最多保留两条有效晨晚记录，不等于实际尝试次数。
- 旧数据缺 session 时默认迁移为 morning；非法结构被过滤。兼容旧数据时沿用旧 stores/records.tsx 的校验规则，不做无提示清空。
- 今日状态分别显示 morningDone / eveningDone 与完成时间；晨晚均完成才算“今日全部完成”。旧今日状态还按 timestamp 校正被标记为 evening 的晨间记录（见 brushRepository.ts），迁移时需保留兼容性。

## 统计与完成反馈

- 完成会话数：完成记录条数（去重覆盖后的条数）。
- 完成日期数 / 累计天数：至少一个时段完成的业务日期去重数。
- 晨晚双完成日期数：同一业务日期两时段均完成；不与累计天数混用。
- 连续天数：最近完成日期须为今天或昨天，再向前累计相邻完成日期；任一时段完成即可，今天未刷但昨天完成仍可保持连续。
- 月完成率：所选月完成日期数 ÷ 该月全部自然日数，四舍五入为百分比；不按截至今天的天数计算，不是晨晚双完成率。
- 周统计以周一至周日统计完成会话、总时长与平均时长；无记录的平均时长为 0，平均时长按秒四舍五入。
- 完成反馈包含用时、15 步、连续天数及鼓励文案。里程碑为 3、7、14、30、60、100、365 天，恰好达到时给出反馈。
- 晨间完成且晚间未完成，提示晚上再来；晚间完成则提示明天见；双完成提示今天任务全部完成。
- 仅有本机完成记录，不能计算全产品 DAU、跨设备留存或开始到完成的转化率。

## 本机资料与设置

- user_profile_cache 保存昵称和头像；不引入登录账号或后端鉴权。本机资料授权标志不等于服务端账户。
- user_settings 默认：reminderEnabled=false、reminderTime='07:30'、soundEnabled=true、voiceEnabled=true。
- 提醒开关只保存偏好，不自动推送。开启时说明暂不支持推送并建议设置手机闹钟。
- 历史、资料与设置需跨页面共享并持久化；后续可采用旧项目的 Zustand vanilla + Taro 存储适配方式。本空项目不预装业务状态库或实现 stores。
